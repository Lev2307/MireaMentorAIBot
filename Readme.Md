# 👾 Бот ИИ-ассистент для студентов РТУ МИРЭА

## ⚡Запуск бота
1. *Клонировать репозиторий с гитхаба*  
```git clone https://github.com/Lev2307/MireaMentorAIBot.git```
2. *Создать виртуальное окружение и запустить его*  
```py -m venv venv```  
```env\Scripts\activate```
3. *Перейти в папку с проектом*  
```cd MireaMentorAIBot```
4. *Загрузить все нужные библиотеки из файла requirements.txt*  
```py -m pip install -r requirements.txt```
5. *Запустить бота*  
```py main.py```
